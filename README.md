# Бот посещаемости (Telegram Mini App)

Студент открывает мини-приложение → выбирает пару → «Был / Не был». Преподаватель видит, кто отметился, может править отметки, вести список студентов и грузить расписание. Выгрузка в CSV: `/export НАЗВАНИЕ_ГРУППЫ`. Бэкап базы: `/backup`.

## Запуск
1. @BotFather → `/newbot` → получите токен.
2. Залейте папку в репозиторий GitHub.
3. Railway/Render/Fly (или свой VPS) → «Deploy from GitHub repo» (используется Dockerfile).
4. Подключите **Volume** на `/data` (иначе база сотрётся при редеплое).
5. Переменные окружения — см. `.env.example`. `BASE_URL` — HTTPS-адрес, который выдал хостинг.
6. Напишите боту `/id`, впишите свой ID в `OWNER_IDS`, перезапустите.
7. Откройте бота → «Журнал».

## Расписание
- Ссылка на календарь **ICS** (iCal) — вставляется в карточку группы. Многие вузовские сайты (в т.ч. ruz-системы) умеют экспорт в ICS.
- Либо `SCHEDULE_URL_TEMPLATE` с `{group}` — тогда расписание грузится по названию группы.
- Либо пары вручную. Повторная загрузка ICS обновляет пары, дубликатов нет.

## Локально
`pip install -r requirements.txt`, задать переменные, `python bot.py`; для HTTPS — `ngrok http 8080`.
